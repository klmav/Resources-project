# Resource Plan Auditor Bot (Google Sheets)

Чат-бот и сервис-проверяльщик ресурсного плана в Google Sheets:
- читает ресурсный план из Google Sheets
- запускает набор проверок (валидации качества данных)
- формирует рекомендации/предложения исправлений
- отправляет уведомления в чат (и/или email) при проблемах

Это **вариант 2**: отдельное приложение + Google Sheets API + чат-бот.

## Быстрый старт (локально)

1) Создай виртуальное окружение и поставь зависимости:

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

2) Скопируй `env.example` в `.env` и заполни значения.

3) Запусти “аудит” (пока это каркас: читает конфиг и выполняет заглушечные проверки):

```bash
python -m src.main audit
```

## Локальный режим (XLSX выгрузка) — рекомендуемый старт

Если пока не хотим настраивать доступ к Google Sheets, можно проверять локальную выгрузку `.xlsx`:

```bash
python -m src.main audit-xlsx --path auto
```

`--path auto` возьмет **первый .xlsx** файл в папке проекта (удобно на Windows, если имя файла с кириллицей).

Полезные флаги:
- `--limit 80` — сколько проблем печатать (остальное останется в “… и ещё N”)
- `--full` — печатать всё (может быть очень длинно)

Отчет включает сводку:
- топ проблем по типу
- топ PM по количеству “пустых месяцев” (MONTH_CELL_EMPTY)

## Исправления (preview/apply) — безопасно

Бот умеет подготовить “пакет правок” для самой частой проблемы:
**пустые ячейки на 2 месяца вперед** → поставить `0`.

Принцип безопасности:
- сначала **preview**
- затем **apply**
- правки применяются **в копию XLSX**, оригинал не трогаем

Команды в Telegram:
- **`/fix preview`** — показать, сколько ячеек будет заполнено `0`
- **`/fix preview <ФИО PM>`** — то же, но только по одному PM
- **`/fix apply`** — применить правки и сохранить **в новую копию** в папку `LOCAL_XLSX_OUTPUT_DIR` (по умолчанию `out/`, имя с датой/временем)

В preview бот также показывает **топ‑10 примеров** (с адресом ячейки, месяцем, сотрудником и PM).
Дополнительно бот может “подсветить” (highlight) ячейки **пустого PM / пустого ФИО сотрудника**
в строках, где есть запланированные дни — без автозаполнения.

## Еженедельное информирование (этап 2)

Бот может автоматически слать **еженедельный аудит** в `TELEGRAM_CHAT_ID` на **3‑й рабочий день недели**
(обычно это **среда**).

Настройки в `.env`:
- `WEEKLY_REPORT_ENABLED=1`
- `WEEKLY_REPORT_TIME=10:00` (локальное время)
- `WEEKLY_REPORT_TZ=Europe/Moscow`

---

## Уточнение загрузки сотрудника (ч/д и %)

Команда:
- **`/load <ФИО> <месяц>`**

Примеры:
- `/load Иванов Иван 01.26`
- `/load Петрова Анна 2026-02`

Результат:
- **ч/д** = сумма по всем строкам этого сотрудника в выбранном месяце
- **%** = ч/д / “рабочие дни месяца” (из сервисной строки над шапкой) * 100

4) Запусти Telegram-бота (polling):

```bash
python -m src.main bot
```

Примечание: для команды `bot` нужны дополнительные зависимости.
Установи:

```bash
python -m pip install -r requirements-bot.txt
```

Для `audit-xlsx` они **не нужны**.

## Конфигурация (.env)

Смотри `.env.example`. Минимально нужно:
- **`GOOGLE_SHEET_ID`**: id таблицы
- **`GOOGLE_SHEET_TAB`**: имя листа/вкладки
- **`GOOGLE_AUTH_MODE`**: `service_account` (рекомендуется) или `oauth_user`

Для Telegram-уведомлений:
- **`TELEGRAM_BOT_TOKEN`**
- **`TELEGRAM_CHAT_ID`**

## Как будет выглядеть работа (целевое поведение)

- По расписанию (например, каждый день в 09:00) сервис запускает проверки
- Если найдены ошибки/пропуски — отправляет сообщение в чат
- В чате можно написать:
  - “проверь план” → получить отчет
  - “покажи ошибки по Иванову” → фильтрация
  - “применить исправления” → бот внесет изменения в таблицу (после подтверждения)

## Как дать доступ к Google Sheets (service account)

В этом проекте MVP использует **service account**.

Тебе нужно:
- создать service account в Google Cloud и скачать JSON ключ
- сохранить ключ локально (например `secrets/service-account.json`)
- **расшарить таблицу** на email сервис-аккаунта (как обычного пользователя, роль Viewer)

После этого `python -m src.main audit` сможет читать таблицу без логина в браузере.
