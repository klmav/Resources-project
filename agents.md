# Agent Guide (для разработки в этом репозитории)

Этот файл описывает правила работы “как агент” (человек или AI), чтобы код и изменения были предсказуемыми.

---

## Цель репозитория

Сделать сервис + чат-бот, который:
- читает ресурсный план из Google Sheets
- применяет набор проверок качества данных
- формирует рекомендации/предложения исправлений
- уведомляет о проблемах и (опционально) применяет правки

---

## Принципы

- **Сначала безопасность**: доступы к Google/боту — только через переменные окружения, секреты не коммитим.
- **Детерминированные проверки**: проверки должны быть воспроизводимыми, без “угадываний”.
- **LLM — только для текста**: модель помогает формулировать сообщения/рекомендации, но не должна “придумывать” факты.
- **Подтверждение на изменения**: любая запись в Google Sheets — только после явного подтверждения пользователя (по умолчанию).

---

## Как мы работаем с таблицей

- Мы не “парсим глазами”: сначала фиксируем **контракт данных** (см. `docs/tech.md`):
  - какие колонки/поля считаются источником истины
  - как определяется “незаполнено”
  - как определяется “capacity” сотрудника
- Любая новая проверка добавляется как отдельная функция/класс в `src/checks/`.

---

## Стандарты кода

- Python 3.11+
- Типы: по возможности добавлять type hints
- Логи: структурные, без секретов
- Ошибки: “fail fast” на неправильной конфигурации

---

## Команды (Windows-friendly)

Установка:

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

Запуск аудита:

```bash
python -m src.main audit
```

---

## Как вносить изменения

- Не делаем “большие коммиты-мешки”: один PR/набор изменений — одна тема.
- Документацию обновляем вместе с кодом (если меняется поведение).
- Если добавляешь переменную окружения — обнови `.env.example` и `docs/tech.md`.
